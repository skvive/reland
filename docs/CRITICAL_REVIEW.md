# RE:LAND v1.1 — 비판적 설계 검토 및 납품 전 품질 보고서

검토 기준: 2026-10-29. 이 문서는 실제 구현된 기능과 출시 전 필요한 외부 연동을 의도적으로 구분합니다.

## 1. 제품 정의

- **비전:** 전국 도시정비사업을 주민의 관점으로 이해하고, 변화를 공유하는 지도 기반 지역 SNS.
- **서비스 대상:** 주민, 임차인, 토지등소유자, 조합원, 전문가, 지역 사업 관계자.
- **브랜드:** RE:LAND (리랜드) / 슬로건 “우리 동네의 내일을 잇다.”
- **정보 계층:** 공적 사실(고시/공공데이터) ≠ 언론 기사 ≠ 사용자 의견 ≠ 법률 자문.
- **지도:** OpenStreetMap / Leaflet 사용. 오프라인·지도 라이브러리 차단 시 정확 지도가 아닌 **도식적 지역 안내**로 폴백.
- **사회적 연결:** 비공식 주민모임 팔로우, 글·질문·댓글, 북마크·신고·공유 링크, Google 계정으로 로그인.

## 2. 공공데이터 현실성 검토

| 항목 | 현재 확인된 사실 | 구현 방침 | 남은 과제 |

## 3. 도메인·권한 모델

- 비로그인: 지도·정비사업 정보·공개 게시글·뉴스·법률 기초 안내 열람.
- Google 로그인: 개인 프로필, 비공식 커뮤니티 생성, 팔로우, 글쓰기, 댓글, 좋아요, 북마크, 신고, 상담 접수.
- 조합 관련 확인 요청: **pending → approved/rejected**; 운영자 검증 별도. 승인은 서비스 내 확인 표시에만 사용하며 법적 조합원 자격을 생성하지 않습니다.
- 공식 조합 커뮤니티: 운영자가 법인/대표 권한 자료를 별도로 검증한 경우에만 `official` 표기를 승인할 수 있는 관리자 API 및 감사 로그를 지원.
- 운영자: 별도 `X-Admin-Key`로 신고 조회, 글 숨김, 인증 요청 심사, 공식 표시 관리. 키는 웹 프런트엔드에 두지 않음.

### 명확한 비목표

법정 조합 설립·총회·전자투표 기능을 리랜드의 일반 게시판으로 대체하지 않습니다. 조합원 명부를 업로드하도록 요구하지 않습니다. 부동산 투자수익, 입주확정, 조합원 권리 등을 단정하지 않습니다.

## 5. 기술 아키텍처

```text
Browser / PWA (반응형 HTML+CSS+순수 JavaScript)
  ├─ Google Identity Services -> Google signed ID token
  ├─ Leaflet + OpenStreetMap tiles (online, optional)
  └─ same-origin JSON API
      └─ Python FastAPI
          ├─ RS256/JWKS Google ID token verification
          ├─ HttpOnly session cookie & CSRF Origin check
          ├─ SQLite (users, sessions, districts, communities,
          │         posts, likes, comments, reports, consultations,
          │         audit_events, news)
          ├─ opt-in official CSV importer
          ├─ public RSS metadata collector
          └─ optional SMTP notification
```

## 7. 외부 연동 진위 구분

1. **Google 로그인:** 실제 ID 토큰 검증 코드는 구현. OAuth Client ID, 도메인 설정 및 실제 Google 계정으로의 운영 검증은 별도.
2. **공공데이터:** 연간 공식 CSV 수동 가져오기 구현. 공공데이터 API를 자동 호출하지 않습니다.
3. **실시간 뉴스:** RSS 수집 코드 구현. 외부 네트워크/검색 공급자 응답 실패 시 빈 상태 표출.
4. **Blogger:** 개인·모임별 공개 blogspot.com 링크 및 공개 RSS 열람만 제공. 계정 소유확인, 게시물 자동 발행, 비공개 블로그 접근 기능은 후속 버전.
5. **실제 전문가:** 상담 등록 시스템 구현. 전문직의 명단·소속·자동 배정은 없는 상태입니다.
6. **실사·3D:** AI 생성 조감 이미지는 실제 도시계획 확정 조감도나 지적도 아님. 3D 타일·WebGL 건물 메시·정비구역 경계 추출은 미구현.

## 8. 자동 테스트 및 화면 검수

### 단위·API 테스트

`python -m pytest -q tests` 명령으로 19개 테스트 통과 확인. 범위:
- Google 위조 ID 토큰 거부 / 데모 인증 운영환경 차단 / 세션 생성·삭제
- 실제 공공데이터 0행 vs 시연 지역 허브 17개 분리
- 회원 미인증 쓰기 거부 / 모임 생성·팔로우 / 인증요청
- 게시글 작성·댓글·좋아요 토글·북마크·신고
- 상담 동의 검증 / Blogger SSRF 유사 URL 거부
- 관리자 비인가 접근 차단 / Origin 교차 출처 차단
- RSS 메타데이터만 사용 / CSV dry-run 및 실제 반영
- 직접 주소 진입 시 SPA 응답 / 질문 해결 상태 / 게시글 작성자 삭제
- 사용자 탈퇴 및 글 익명화 / 관리자 공식 모임 승인 권한 / 모임별 Blogger URL 검증

### 브라우저 화면 검수

Chromium headless에서 다음 DOM 동작을 테스트: 홈 표시, 지도 17개 검색결과, 커뮤니티 생성 모달, 체험 로그인, 신규 모임 생성, 게시글 발행, 댓글 작성, 상담 폼 표시, 390px 모바일 가로 오버플로 없음. JavaScript 페이지 예외 0건. 화면 캡처를 `docs/home-desktop.png`, `docs/map-desktop.png`, `docs/home-mobile.png`, `docs/experts-desktop.png`에 포함.

**중요한 테스트 한계:** 실행 컨테이너 정책상 Chromium의 외부/로컬 웹주소 직접 탐색이 차단되어, 브라우저 화면 검수는 로컬 HTML/CSS/JS를 주입하고 실제 FastAPI TestClient 요청을 연결하는 방식으로 수행했습니다. 이는 전체 HTTP 브라우저·DNS/TLS·실제 Google SSO·뉴스 서버 연결에 대한 운영 E2E 검증과 **동일하지 않습니다.** 실제 배포 환경에서 별도 검증 필요.

| 관심구역 | 실데이터를 구역 ID별 저장·해제 | 로그인 권한·데모 차단·개인 목록 검증 | 푸시/문자 알림 전송은 미구현 |
| 단계 변화 | 원본 CSV 재가져오기에서 추진단계 값이 변경되면 이력 저장 | 동일 단계 반복 무변경·변경 기록 1건 확인 | 원본 다운로드 자체는 수동, 연간 갱신 자료 |
| 정확 경계 | 감사된 WGS84 FeatureCollection만 CLI로 적재, 원본 링크·기준일 기록 | 폴리곤 구조·좌표·DB 일치·드라이런 검증 | 자동 원본 검증·좌표계 변환·대량 지자체 매칭 불가 |
| 지도 | 정확 자료가 등록된 구역만 Leaflet 경계 렌더 | 브라우저 코드 문법 및 API 응답 확인 | 전체 전국 경계는 확보되지 않음 |
| 게임형 개인 공간 | 글/댓글/팔로우/관심구역 기반 점수·배지 | 개인 전용 대시보드·배지 계산 검증 | 경제적 보상/공식 등급 아님 |
| 상담 사건 상태 | 운영자 API로 상태 관리, 회원에게 본인 이력 표시 | 관리자 권한 차단·이력 및 감사 SQL 확인 | 변호사 자동배정/실시간 답변 없음 |
| 실행 | Windows `.env` 자동 준비 및 Python 서버 실행 | 모듈/프런트 구문·API 자동 검사 | 실제 Windows PC 설치환경은 이 Linux 환경에서 미검증 |

**현재 검증 총계:** pytest API/DB/권한/공간정보 관련 30개 통과, Node.js 정적 JS 구문 검사 통과. Chromium 화면 주입 검수 홈/지도/로컬 체험 로그인/개인 대시보드/390px 모바일 가로 넘침 없음, JS 페이지 오류 0건. `tests/ui_smoke.py`로 재현 가능합니다.

**검증 불가/출시 보류:** 진짜 Google 계정으로 SSO, 정부 원본 파일 자동 다운로드(공공데이터포털 네트워크 접근 불가), 실제 조합원 증빙의 법적 판별, 경계 원본의 진위, 지도 타일 실접속, 뉴스 RSS 실수집, 전문직 계약·상담배정, 운영 도메인 DNS/TLS/대량 접속, Windows PC에서 설치·실행 여부, 3D GIS/AR 위치게임.


## v2.0 고도화 검토

- 변호사·법무사·행정사 플랫폼은 업무범위 및 광고 규정이 서로 다릅니다. 유료 광고·전문가 연결이 직역별 광고 및 사건 소개/알선 금지 규정에 저촉되지 않도록 법률 전문가의 사업모델 검토 필수.
- 관리자 승인과 자격확인은 **운영자 수동 검토 API 구현** 단계이며 대한변호사협회·법무사협회·행정사 등록기관 실시간 조회 연결은 제공하지 않습니다.
- 광고비 실결제, 건당 상담 알선, 성사 수수료, 자동 추천 순위는 의도적으로 미구현입니다. 이벤트 수치도 과금 지표로 사용할 수 없습니다.
- 법률 저널 120편은 **고유 제목·본문으로 생성한 초안**이며 저명 전문가가 직접 검수·서명한 콘텐츠가 아닙니다. 원문 일부 발췌가 포함되어 있으며 전체 조문은 법제처 공식 원문 링크에서 확인합니다.
- Google Blogger 자체 개설은 비지원(공식 Blogger API Blogs.insert 없음), 관리자 OAuth 없이 외부 게시되지 않습니다. 비공개 초안 생성 도구는 준비되어 있습니다.
- YouTube Shorts 실제 영상 게시·YouTube 조회수 표시 및 외부 저작권 콘텐츠 사용 허락은 미확인. 큐레이터가 URL을 승인한 콘텐츠만 표시합니다.
- 로그인 OAuth, 외부 송신/광고계약, 개인정보 약관, 최신법령 동기화, 현장 기사 검수, 고도화된 보안은 실제 운영 검수가 필요합니다.
