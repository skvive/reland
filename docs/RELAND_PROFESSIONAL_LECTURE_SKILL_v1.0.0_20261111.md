# RE:LAND 강실장 고객납품형 교육자료 제작·검수 스킬

## 원칙
1. 사용자 승인 마스터 `kang_blog/assets/kang-master-approved-20261111.jpg`를 동일한 얼굴의 소스로 사용한다. SHA-256 `c048b5c64745d5a59d7a9ebb2c3c3f6d5a7c0aa689958a9f1ce9bde0cc63dc5e`. 사진의 눈·코·입을 생성형 이미지로 재합성하거나 임의 수정하지 않는다. 자세 변형에는 별도 승인 사진이 필요하다.
2. 작업 전에 연결된 Google Drive `ChatGPT_Library/01_PROJECTS/RELAND`, `렉시드개발자료/공통개발스킬`, GitHub `skvive/reland` 실제 파일과 권한을 확인하고 기존 자산을 우선 재사용한다. 원본 파일은 삭제하지 않는다.
3. 모든 60강의 작성 기준은 실제 `kang_blog/data.js` 및 `content/kang/lectures_60.json`에 있는 강의별 제목·범주·원본 설명·학습 시나리오·검토 문서·오류·출처 URL이다. 없는 판례·인증·수치·확정 권리는 임의 보강하지 않는다.
4. 강의 한 편 구성은 히어로(16:9), 학습목표·개념, 주제별 단계 도식, 원본 자료 대조표, 가상 실무 사례, 오해하기 쉬운 점, 원문 링크, 자기 점검, 교육·저작권 고지를 포함한다. 새로운 사실 주장을 단정하지 않고 기존 원고의 교육 내용을 시각화한다.
5. 분야별 10개 교육 시나리오를 공유하되 각각 60강의 개별 주제와 원문 `scenario`, `documents`, `pitfall`을 함께 사용한다. `lesson-v7.js`는 원고를 삭제·덮어쓰기하지 않고 인접 영역에 전문 학습 모듈을 추가한다.
6. 30개 Q&A 정적 교육 화면은 로그인이 없는 이용자도 열람할 수 있어야 한다. 원본 질문·해설과 링크를 유지하며, 버튼은 `aria-expanded`, `hidden`, 검색·범주 필터·딥링크 등 실제 동작해야 한다. Neon DB 응답 장애가 있어도 교육 원고 열람 자체는 가능해야 한다. 댓글·좋아요·북마크 등 계정 기반 쓰기 기능의 성공을 서버 검증 없이 주장하지 않는다.
7. 이미지는 승인 원본을 크롭/합성한 RE:LAND 공식 시안. 헤어라인·상반신·로고·한글 글자가 잘리면 반려한다. 320·375·390·430·768·1024px 모바일/태블릿에서 실제 페이지 가로 넘침과 버튼 터치 영역을 검수한다.
8. 사용자 요청에 따른 각 강의 하단 안내: ‘리랜드 강실장’은 교육 콘텐츠이며 본사는 법률상담·사건 수임·대리·개별 자문 및 변호사 광고를 제공하지 않는다. 개별 사건 상담 문의를 삼가도록 요청한다. 리랜드가 권리를 소유한 IP의 사익적 무단 사용은 금지, 출처 표기·저작권 보존 조건 공익적 비영리 배포는 허용한다. 제3자 저작물·법령·판례의 권리는 각 권리자에게 있다. 해당 공지는 법령 준수의 최종 법률 판단을 의미하지 않는다.
9. 강의 하단에 변호사 입점·광고·상담 유도 버튼을 배치하지 않는다. 강의 상세 이동·원문 확인·교육용 정보만 연결한다.
10. QA: JSON 소스 60강/30 Q&A 개수 확인, JS 문법 검사, HTML·CSS 유효성/이미지 크기 검사, 링크 경로·접근성 검수, 6개 이상 화면폭 테스트, Vercel READY와 서버 로그 확인, 공개 도메인의 실제 HTTP 응답을 별도 구분 보고한다.
