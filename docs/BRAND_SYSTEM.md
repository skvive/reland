# RE:LAND Brand System (v1.0 · 2026-10-29)

## Brand grammar

| Token | Value | Use |
|-------|-------|-----|
| Forest deep | `#0f3d36` | Header, footer, hero overlay |
| Forest | `#11645b` | Primary buttons, links |
| Lime signal | `#d6f76b` | Accent, colon in RE:LAND, CTAs |
| Paper | `#fafbf7` | Page background |
| Ink | `#18312f` | Body text |
| Muted | `#6a7d79` | Secondary copy |

**Voice:** 신뢰·공공데이터·이웃 연결. 과장·투자 권유·법률 자문 암시 금지.

**Logo:** `static/assets/logo-reland.svg` + mark `icon.svg`. Minimum clear space = mark height.

**Imagery:** 실사/포토리얼 도시·주거 재개발 맥락. AI 생성 시 캡션·alt에 “콘셉트·실제 고시 도면 아님” 표기.
