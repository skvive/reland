# RE:LAND | 강실장 인물 동일성 고정 · 저널 브랜드 워터마크 스킬

## 우선순위와 원본
1. 가장 최신의 사용자가 직접 승인한 사진을 확인한다. 이 버전의 **고정 마스터**는 `kang_blog/assets/kang-master-approved-20261111.jpg`이며, SHA-256 = `c048b5c64745d5a59d7a9ebb2c3c3f6d5a7c0aa689958a9f1ce9bde0cc63dc5e`, 원본 픽셀은 **1536×864**이다. 실존 인물의 신원 판단이나 사진의 진정성 검증을 의미하지 않는다.
2. 소스 검색 순서: 사용자 승인 원본 → Google Drive `ChatGPT_Library/01_PROJECTS/RELAND` 및 `렉시드개발자료/공통개발스킬` → 기존 `skvive/reland` 코드/이미지 → 추가 제작. 쓰기 전 권한과 실제 파일 내용을 확인하고, 백업·업로드 전 중복 파일 이름과 SHA-256을 비교한다.
3. 원본 사진·OG·기존 강의 이미지와 코드 파일은 검증·배포 확인 전 **삭제하지 않는다**. 신규 에셋만 `-v6` 등 버전 식별자를 추가한다.

## 절대 규칙: 얼굴은 생성하지 말고 원본을 붙여 넣는다
- 강실장 얼굴의 눈·코·입·얼굴형·헤어라인을 매 작업마다 새로운 AI로 그리지 않는다. Text-to-image, image-to-image, face swap, Meshy 생성 모델을 인물 동일성의 최종 소스로 사용하지 않는다.
- **정확한 이미지 컴포지팅(PIL/PSD/Figma layer)** 사용: 승인 인물 이미지를 *픽셀 그대로* 리사이즈/크롭 또는 투명 오려내기한 뒤 배경 위에 배치한다. 디자이너가 원본 얼굴에 페인트·리터칭·재생성·생성형 채우기를 적용하지 않는다.
- 포즈가 바뀌는 장면이 필요한 경우 진짜 승인된 다른 각도·자세의 원본 사진을 받아 교체한다. 같은 사진에서 다른 포즈가 생겼다고 가장하지 않는다. 별도 원본이 없다면 배경·텍스트·카드 색상·촬영 앵글 *크롭*만 변주한다.
- 이 버전 10개 주제 배너는 모두 정확히 같은 `kang-master-approved-20261111.jpg`로 합성한다. 캐릭터 얼굴이 있는 임의 AI 생성 배너들을 카테고리 표시의 기준으로 사용하지 않는다.
- 인물 이미지의 사용 권한은 소유자/제공자의 범위 안에서만 사용한다. 공개 배포 자산에 사진 활용권이 불확실하면 우선 검토한다.

## 배너 레이아웃 규격
- 마스터: 1600×900 (16:9), WebP 85–90 품질. 강의 카드: 16:9 **object-fit: contain**; 비율과 크롭이 일치하도록 CSS를 유지한다. 상단 헤어라인, 아래턱, 어깨, 제목/로고를 절단하지 않는다.
- 모바일 320/360/375/390/430px 및 태블릿 768px에서 모두 레이아웃과 가로 스크롤을 검사한다. 카테고리별 배너 제목은 텍스트 크기를 가변으로 축소하여 잘림을 막는다. 본문에는 읽을 수 있는 HTML 제목도 별도로 제공한다.
- 색: 딥그린 `#103B30`, 크림 `#F4EBD9`, 골드 `#E5C994`, 밝은 화이트. 리랜드 로고는 사용자 승인 `RE:LAND` 시안의 비율과 글자꼴을 유지한다.
- 한 배너 안에서 인물 1회만 등장하도록 한다. 홈페이지 인접한 2장 중 한 장은 인물 없는 도시/재개발 배경으로 구성한다.
- 임의 수강생 수·만족도·전문가 자격·확정 사업지 데이터 등 사실 주장과 합성을 결합해 실재 근거처럼 보이게 하지 않는다.

## 강의 연결 규칙
- 실제 `kang_blog/data.js`의 **60강·10개 분야** 순서를 확인한다. 강의 ID/분야를 로직으로 매핑하고 `kang-identity-category-01-v6.webp` ~ `-10-v6.webp`를 표시한다.
- 동일 배너를 동적으로 가리키는 곳: 강의 목록 카드, 모달 상단, 추천 강의 카드, 교육 문의 안내. 강의 제목·분야는 **실제 데이터**를 사용한다. 원고·법령 링크·상세 데이터는 변경하지 않는다.
- 카테고리 사진을 매 강의마다 새롭게 AI로 생성하지 않는다. 강의실 히어로는 승인 마스터를 배경으로 하고, 문자 콘텐츠는 HTML로 표현하여 접근성을 유지한다.

## 저널 워터마크·저작권 표시
- 원본 저널 120개 `static/assets/columns/column-001.webp`~`-120.webp`는 수정·삭제하지 않는다. 재표시할 때 `/journal-image/{id}.webp`가 인메모리로 워터마크를 합성하여 내려준다.
- 공통 오버레이 `static/assets/journal-watermark-overlay-v6.png`: 좌측 상단 `RE:LAND 저널`, 우측 아래 `© RE:LAND | 무단 복제·배포 금지`, 중앙 낮은 불투명도 서명. 다운로드 경로에도 합성된 픽셀을 포함한다. 일반 시각적 경고이며 DRM/불법 복제를 완벽하게 차단하지는 못한다.
- 소유/사용 허락이 확인된 리랜드 제작 이미지에만 저작권 보유 표시를 사용한다. 타사 이미지에 배타적 권리가 있다고 오인시키지 않는다. 법령·판례 원문 자체에 신규 저작권을 주장하지 않는다.
- 저널 카드 및 상세화면 모두 동일 `/journal-image/{id}.webp`를 참조한다. 법률 감수 전 편집 초안 및 AI 생성 콘셉트 이미지 고지는 유지한다.

## QA/배포 체크
1. 고정 사진 SHA-256이 manifest와 일치하는지 확인한다.
2. PNG/WebP 이미지 1600×900 및 코너 로고와 헤어라인 잘림 여부를 육안 검수한다.
3. 저널 미디어 GET은 1~120만 허용; 200 + image/webp, 0/121은 404. 동적 합성 이미지는 실제 픽셀에 워터마크가 포함되는지 검사한다.
4. 강의 10개 분야별 이미지 경로와 강의 카드·모달·추천 강의가 같은 v6 파일을 참조하는지 확인한다.
5. 기존 SEO, Google/Naver 메타 인증, 로그인/API, CSS/JS 접근성을 유지한다.
6. 테스트·GitHub 변경 read-back·Vercel `READY` 및 공식 도메인 별칭 확인 후 완료 보고한다. 실제 브라우저 E2E를 수행하지 않았으면 그 사실을 명확히 쓴다.
7. Google Drive와 GitHub에 버전명·체크섬·수정 이력을 남기고 원본을 그대로 보존한다.
