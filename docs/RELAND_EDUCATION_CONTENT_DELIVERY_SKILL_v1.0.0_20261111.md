# RE:LAND | 강실장 전문 교육자료 제작·검수 스킬

## 소스 우선순위
- 사용자가 승인한 원본 강실장 사진 및 RE:LAND 로고 고정. `RELAND_IMAGE_IDENTITY_COMPOSITING_SKILL_v1.0.0_20261111` 적용. **생성 AI로 얼굴 다시 그리기 금지**. 이미지 합성만 허용.
- `kang_blog/data.js`, `content/kang/lectures_60.json`, 기존 `kang_blog/slides/`의 실제 내용·조문 링크·사례를 재사용한다. 이미 기재된 자료 근거 없이 구체적 수치·확정 판례·조합 인가 사실을 추가하지 않는다.
- Google Drive `ChatGPT_Library/01_PROJECTS/RELAND`와 `렉시드개발자료/공통개발스킬`의 파일 내용·쓰기 권한·중복 여부 확인 후 새 버전 제작.

## 고객 납품용 60강 공통 포맷
1. 강의번호·카테고리·주제 제목·교육적 수준과 출처 표기. 2. 실사형 16:9 히어로(동일 인물 픽셀 합성, `contain`으로 얼굴 크롭 금지). 3. 학습 목표, 핵심 개념, 확인할 문서, 흔한 오류 세 칼럼. 4. 절차 흐름도, 기존 강의별 SVG 개념도. 5. 원본 7개 강의 단락을 충실히 담아 소제목과 도식, 가상 사례로 읽기 좋게 재구성. 6. 실무 체크리스트(작성기관·기준일·원문 대조 등), 자기 점검 문제. 7. 공식 법령·검증된 판례 원문으로 가는 링크(시행일 재확인 안내). 8. 마지막에 교육목적·법률상담 불가·IP 이용 안내 표기.

## 법규·광고 구분
- 서비스는 교육정보 제공만 한다. 강실장 강의 및 Q&A 화면에 개별 사건 법률상담 모집, 변호사·법무법인 광고, 연락처 광고, 사건 수임·대리 CTA를 삽입하지 않는다. '상담하기' 대신 '강의 보기' 또는 '원문 확인' 사용.
- 교육자료는 전문 법률 자문/계약서·고소장 작성 서비스가 아님을 명확히 쓴다. 구체적 법률 주장/인용은 국가법령정보센터 최신 버전과 사례별 관할 규정을 사후 검증하되, 이 문서 자체가 법규 준수를 보증하지 않는다.
- 사용자 요청 고지 취지: ‘리랜드 강실장’의 교육목적, 법률상담 전혀 하지 않음, 개별 사건 상담문의 자제, 변호사 광고 미게시, 사익 목적 IP 무단 사용 금지, 출처 표시한 공익적 비영리 배포 허용. 법령·판례·제3자 저작권은 존중.

## QA·리그레션 테스트
- 각각의 60개 강의 ID는 한 개의 동일 템플릿에서 제목·원본 7개 페이지·도식·문서·참고법령을 정확히 불러오는지 검사.
- 30개 Q&A 카테고리·상세 링크·좋아요/공유/신고/댓글 버튼, 로그인 필요 상태, 네트워크 오류 메시지 확인. 404와 500을 구분하고 데이터베이스 연동의 PostgreSQL·SQLite 호환 쿼리를 테스트한다.
- 320/375/390/430/768/1024/1280px 가로 넘침, 폰트 최소 크기, 44px 터치 영역, 인물 머리 절단, 모바일 상단·하단 내비 가림 확인.
